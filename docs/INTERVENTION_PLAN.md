# Plano de Intervenção

## Fase 1 — Segurança imediata
1. Remover equipamentos portáteis do eixo de circulação.
2. Organizar/ocultar cabos.
3. Verificar estabilidade de aparador e TV.
4. Definir lugar fixo para bengala e objetos de uso frequente.

## Fase 2 — Acessibilidade
1. Testar assentos com braços e firmeza adequada.
2. Validar altura real para sentar/levantar.
3. Reposicionar mesa/cadeiras após levantamento métrico.

## Fase 3 — Cognição e orientação
1. Reduzir clutter.
2. Criar referências visuais estáveis.
3. Inserir relógio de leitura fácil sem excesso de sinalização.
4. Preservar fotos/objetos familiares selecionados.

## Fase 4 — Iluminação
1. Equalizar luz natural e artificial.
2. Inserir luz de apoio no estar.
3. Criar balizamento noturno.
4. Rever reflexos na TV.

## Fase 5 — Redesign estético
1. Marcenaria e mídia.
2. Tecidos e cortinas.
3. Paleta final.
4. Curadoria de objetos e plantas.
